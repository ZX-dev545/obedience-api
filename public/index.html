Obedience API

Describe the behaviour. Get the mechanism.

Obedience uses symbolic reasoning to build what you describe. Give it examples of the behaviour you want and the parts you have to work with, and it rapidly infers how to put them together.

Quickstart

Three steps

1

Install the client

It has no dependencies.

pip install git+https://github.com/ZX-dev545/obedience-api
2

Generate a key, then submit

Use the button at the top of the page, then send a job and wait for it.

from obedience_api import ObedienceApiClient

client = ObedienceApiClient(
    "https://obedience-api.vercel.app",
    api_key="YOUR_API_KEY",
)
job_id = client.submit_job(job)
status = client.wait_for_job(job_id)
print(status.status, status.result, status.error)
3

Read the status

Jobs stay queued while no solver is online. The request format is in the README.

queued | running | completed | failed
